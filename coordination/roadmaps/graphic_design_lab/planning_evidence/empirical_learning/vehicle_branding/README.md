# GDL empirical direction — Vehicle Branding

Status: **ACTIVE EMPIRICAL / KNOWLEDGE-SATURATION DIRECTION**

This direction studies vehicle branding as a distinct Graphic Design Lab product family.
It is intentionally maintained in the human + assistant empirical lane.

It does **not** initialize runtime, select a provider, authorize Creator execution,
enable production write, or self-activate engineering implementation.

## Core model

Vehicle branding is not only a visual-design problem. It combines:

1. vehicle identity and exact body configuration;
2. reference geometry and later physical measurement;
3. customer identity / logo / heraldic asset normalization;
4. concept visualization for approval;
5. production technology selection;
6. production-file preparation after approval;
7. installation-aware layout constraints.

The working sequence is:

```text
customer request + photos + identity assets
        ↓
vehicle identity / configuration intake
        ↓
reference geometry search
        ↓
asset normalization requirements
        ↓
machine-readable Intake package
        ↓
machine-readable Creator request
        ↓
FIRST REVIEWABLE VEHICLE CONCEPT
        ↓
customer approval
        ↓
verified measurements / exact geometry
        ↓
production technology decision
        ↓
production package
```

## Two-stage approval boundary

### Stage A — concept visualization

Goal: show how the branding should look on the real vehicle.

The concept may use verified vehicle references or provisional geometry, but any
unverified geometry must be explicitly marked.

The concept is **not production-ready**.

### Stage B — production package

Begins only after concept approval and sufficient geometry confirmation.

Production output may include:

- side-specific vector artwork;
- plotter-cut color separations;
- print files;
- print-and-cut contours;
- panel segmentation;
- installation margins / overlaps;
- material notes;
- production manifest.

## Geometry rule

Internet vehicle drawings/specifications are reference geometry, not final production truth.

Before production, prefer this authority order:

1. measured real vehicle;
2. verified manufacturer/body-builder technical drawing for the exact configuration;
3. verified vehicle-specific template;
4. customer-supplied dimensional evidence;
5. internet reference as provisional concept-only support.

## Production technologies in scope

- colored self-adhesive film / plotter cut;
- printed white self-adhesive film;
- print + contour cut;
- hybrid construction.

## Asset normalization

Customer logos, coats of arms and official marks require a separate normalization step:

- inspect source quality;
- preserve official identity meaning;
- recover/vectorize geometry when justified;
- normalize transparent background / edge cleanliness;
- normalize color references;
- prepare review and production variants separately;
- do not silently redesign an official symbol.

## Human + assistant lane

The current lane collects real cases, prompt behavior, intake patterns, production constraints,
failure modes and reusable knowledge.

Engineering-worker candidates are recorded separately and remain non-executable until a worker
receives an authorized task.
