# Daily empirical experiment checklist

For each real case:

1. Assign a temporary case ID.
2. Capture the raw request in sanitized form.
3. Select/create the relevant draft loader.
4. Run intake manually.
5. Record question rounds and customer friction.
6. Save the Creator prompt/version.
7. Run Creator through the current manual process.
8. Reference the output location instead of copying heavy artifacts.
9. Record operator acceptance, customer acceptance, explicit satisfaction if known, accepted attempt, and revision count.
10. Record strengths, weaknesses, and failure modes.
11. Note tasks that appear better suited to local tools.
12. Note reusable prompt fragments.
13. Do not turn one observation into global policy.
14. Reconcile these drafts after Blueprint returns the authorized contour.
