# Prepress Hub coordination

This directory holds durable module-side coordination, status, and later
completion/governance surfaces.

`tmp/` is not durable knowledge.

Foundation bootstrap deliberately starts with only the minimum status and
Blueprint-question surfaces. Richer prompt synchronization, completion packets,
assistant handoff, and context packaging must reuse/adapt established ForPrint
patterns in later governed steps rather than inventing incompatible local
variants.
