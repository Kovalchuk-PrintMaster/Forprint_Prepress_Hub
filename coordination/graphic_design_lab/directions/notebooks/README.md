# GDL direction: Notebooks / dated planners

Status: **ACTIVE EMPIRICAL KNOWLEDGE DIRECTION**

This direction collects reusable Intake, Creator-prompt, structure, review and
quality-control knowledge for notebooks, diaries and planners.

The current evidence-backed subprofile is:

`dated_planner_v0_1`

The project must **not** assume that calendar-specific rules apply to every notebook.
Plain notebooks, undated planners and other notebook families remain separate future
subprofiles until real evidence exists.

## Core workflow

```text
customer/operator sources
→ normalized notebook case
→ document structure map
→ first reviewable sample
→ customer/operator direction approval
→ design lock
→ full rollout
→ deterministic structural/calendar QC
→ internal visual review
→ customer review
→ editable package / production hold resolution
```

## Important rule

For long repetitive products, do not ask Creator to "make 160 pages" as a loose prose
instruction.

Intake should first compile a machine-readable structural map: page/spread types,
period, page order, service pages, transition rules, content rules, design locks and
artifact expectations.

Corrections are patch-scoped. Approved pages and the approved design system must not
be regenerated without explicit redesign authorization.
